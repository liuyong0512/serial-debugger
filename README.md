# 串口调试助手 · Serial Debugger

一个基于 **Web Serial API** 的单文件网页串口调试工具。无需安装、无需后端，用 Chrome / Edge 打开 `serial-debugger.html` 即可使用。适合嵌入式开发、固件烧录调试、Linux 终端日志查看等场景。

## 程序说明

本工具把串口终端交互、数据收发和协议传输集中在一个页面里：

- **串口连接**：支持设置波特率、数据位、校验位、停止位和流控；点击醒目的「选择串口…」按钮完成浏览器授权后即可打开设备。
- **终端式交互**：接收区本身就是一个行内输入框，可以直接在接收内容后面打字并按回车发送，不需要另开输入窗口；单个回车（空输入）也会发送换行符，方便向设备发送确认指令。支持文本与 HEX 两种输入模式，以及历史指令上下切换。
- **自适应显示**：可选择显示时间戳、接收偏移、发送回显、自动滚动；文本输出支持 ANSI SGR 彩色转义（16 色、亮色、256 色、RGB 真彩色，以及粗体/下划线/反色/闪烁），能把 Linux shell 那种带颜色的日志原样呈现出来。
- **波特率扫描**：当波特率不确定或出现乱码时，可自动扫描 2400 ~ 921600（含 74880 等非常用速率），按可打印字符比例和错误数评分推荐最可能的速率。
- **错误诊断**：对 `framing error`、`Break received`、缓冲区溢出等串口错误分类处理并给出排查建议；对 `Failed to open serial port` 提供关闭流控重试、重置端口授权等恢复手段。缓冲区溢出属于可恢复错误，会静默续读，不中断连接。
- **XMODEM 文件传输**：内置 XMODEM 协议，支持 128 字节与 1K 数据包、CRC / 校验和两种校验、自动重传。接收时先发 `C` 请求 CRC，无响应退回 `NAK`；发送时等待接收方握手。传输期间原始字节不会刷屏，只显示协议进度日志。
- **本地持久化**：串口参数和快捷指令保存在浏览器本地，下次打开自动恢复。

## 使用方法

1. 用 **Chrome 或 Edge** 打开 `serial-debugger.html`（也可以把它放到 `localhost` 静态服务器上访问）。
2. 点击页面上醒目的「选择串口…」按钮，在浏览器弹窗中勾选你的设备并授权。列表为空属正常现象，浏览器出于安全考虑不会自动枚举串口。
3. 设置波特率等参数，点击「打开串口」。
4. 在下方接收区直接输入内容并按回车发送；需要发送十六进制时把发送模式切到 HEX。
5. 文件传输使用 XMODEM 面板，选择发送或接收后按提示操作。

## 注意事项

- 一个串口同一时间只能被一个页面占用，请先关闭其他占用该串口的程序或标签页。
- 浏览器不会主动提示串口被拔出，通信中断时请检查设备并重新打开串口。
- 如果授权弹窗里找不到设备，先确认系统设备管理器中已出现对应 COM 口，且 USB 转串口芯片（CH340 / CP210x / FTDI 等）驱动已安装。
- Web Serial API 需要安全上下文（`localhost` 或 HTTPS）；部分浏览器或 Linux 发行版可能不支持，建议使用最新版 Chrome / Edge。
- 页面内「使用说明与注意事项」折叠区包含更详细的排错条目。
